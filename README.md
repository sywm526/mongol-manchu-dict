# 满蒙词典 · 静态检索站

基于 [东北大学 CNEAS 在线词典](http://hkuri.cneas.tohoku.ac.jp/) 数据集整理的静态词典检索网站，作为原站不可用时的备用镜像。

**在线访问**：https://sywm526.github.io/mongol-manchu-dict/

## 收录内容

| 页面 | 词典 | 条目数 | 形式 |
|---|---|---|---|
| `mongol.html` | 蒙汉词典 | 52,673 | 卡片式查询应用 |
| `manchu.html` | 满汉词典（满汉大辞典 / 新满汉 / 満漢和 合并） | 95,852 | 卡片式查询应用 |
| `manchu_6.html` | 满汉大辞典 | 45,413 | 表格版 |
| `manchu_72.html` | 新满汉 | 33,235 | 表格版 |
| `manchu_55.html` | 満漢和 | 18,662 | 表格版 |

## 功能（两部主词典）

蒙汉 / 满汉主页面完全照搬 [mongolian-dict-search](https://sywm526.github.io/mongolian-dict-search/) 的结构与交互，仅把配色换成浅色 UI；**没有首字母导航**。

- 「词典查询 / 今日学习」双标签页
- 全文检索：西里尔 / 传统文字、满蒙文、转写、中文释义与例句，命中高亮并标注命中位置（主词 / 释义 / 例句）
- 词性筛选（全部 / 动词 / 名词 / 其他）、匹配位置筛选（全部 / 前段释义 / 后段例句）
- 单词卡片：主词、传统文字（竖排 / 横排切换）、转写、释义、参见注记、页段、来源词典（满汉）
- 已学 / 收藏 / 最近搜索保存在浏览器本地，可导出 / 导入 JSON、清空记忆
- 「今日学习」：10 动词 + 10 名词 + 10 复习
- 单次最多显示 200 条；数据全部内嵌单个 HTML，加载后离线可用

三个表格版为旧版页面，保留原有的列检索、首字母筛选与分页（每页 200 条）。

## 数据说明

- 采集自原站分页接口，按满/蒙文词条首字母全枚举 + 转写字母双轴交叉验证补漏
- 「页段」为纸质原书页码引用（页码+段位 a/b/c），不随词条顺序连续递增
- 满文/蒙文竖排显示需本机安装 **Mongolian Universal White** 或 **Noto Sans Mongolian** 字体
