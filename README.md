# 满蒙词典 · 静态检索站

基于 [东北大学 CNEAS 在线词典](http://hkuri.cneas.tohoku.ac.jp/) 数据集整理的静态词典检索网站，作为原站不可用时的备用镜像。

**在线访问**：GitHub Pages 启用后为 `https://<用户名>.github.io/mongol-manchu-dict/`

## 收录内容

| 页面 | 词典 | 条目数 |
|---|---|---|
| `mongol.html` | 蒙汉词典 | 52,673 |
| `manchu.html` | 满汉词典（满汉大辞典 / 新满汉 / 満漢和 合并） | 95,852 |
| `manchu_6.html` | 满汉大辞典 | 45,413 |
| `manchu_72.html` | 新满汉 | 33,235 |
| `manchu_55.html` | 満漢和 | 18,662 |
| `officials.html` | 满汉大辞典·官名摘抄（含置信度标注） | 2,336 |

## 功能

- 任意列全文检索（满/蒙文、转写、国际音标、中文释义），命中高亮
- 首（满/蒙）字母快捷筛选
- 满汉合并版可按来源词典过滤；官名摘抄版可按类别/置信度（高/中/低）筛选
- 分页渲染（每页 200 条），数据全部内嵌于单个 HTML，一次加载后离线可用

## 数据说明

- 采集自原站分页接口，按满/蒙文词条首字母全枚举 + 转写字母双轴交叉验证补漏
- 「页段」为纸质原书页码引用（页码+段位 a/b/c），不随词条顺序连续递增
- 满文/蒙文竖排显示需本机安装 **Mongolian Universal White** 或 **Noto Sans Mongolian** 字体
